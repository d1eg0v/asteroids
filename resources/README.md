# Resources — audio guide

**Sprites are not needed.** The game is vector-drawn with Canvas strokes — there
are no image assets at all. Only audio is optional.

## Required audio files (exact names)

SFX → `resources/audio/sfx/` (`.wav`):

| File | Used by | Notes |
|---|---|---|
| `fire.wav` | Phase 2/6 | bullet shot |
| `thrust.wav` | Phase 6 | loopable, plays while thrusting |
| `explosion_large.wav` | Phase 6 | large asteroid destroyed |
| `explosion_medium.wav` | Phase 6 | medium asteroid destroyed |
| `explosion_small.wav` | Phase 6 | small asteroid destroyed |
| `ship_death.wav` | Phase 6 | ship killed |
| `extra_life.wav` | Phase 7 | bonus-life jingle |

Music → `resources/audio/music/` (`.mp3`):

| File | Used by | Notes |
|---|---|---|
| `heartbeat.mp3` | Phase 6 | two-note heartbeat pulse; the game speeds it up as asteroids dwindle |

Optional (Phase 7 — the game works without them): `ufo_large.wav`, `ufo_small.wav`,
`ufo_shoot.wav`, `hyperspace.wav` in `sfx/`.

## Fallback

Phase 6 (`src/audio.js`) falls back to WebAudio oscillator beeps when a file is
missing — the game never blocks on asset downloads and runs fine with an empty
audio folder.

## Where to get audio

| Source | URL | License | Notes |
|---|---|---|---|
| Kenney (Digital SFX, Retro Game SFX) | https://kenney.nl/assets | CC0 | bulk packs; no attribution required (still credited) |
| sfxr.me / jsfxr | https://www.sfxr.me / https://jsfxr.com | generated by you — free to use | export `.wav`; perfect for fire/explosions |
| OpenGameArt | https://opengameart.org | varies per item (CC0, CC-by, …) | check each page; log the exact license |
| Freesound | https://freesound.org | varies (CC0, CC-by, CC-by-sa) | log exact license + author |
| Pixabay Audio | https://pixabay.com/music | free, no attribution required | |
| Incompetech (Kevin MacLeod) | https://incompetech.com | CC-by 4.0 (credit required) | music, e.g. heartbeat-style tracks |
| BeepBox | https://beepbox.co | compose your own; check its license note | chiptune music |

Rules:
- Use only CC0 / CC-by / free sources; never bundle anything with an unclear or commercial license.
- Log every file actually used in `resources/CREDITS.md` (author, URL, exact license, date retrieved).
